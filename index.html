Períodos com todos presentes

Janelas de 2027 em que nenhum colaborador está de férias — mesmo que em períodos diferentes ao longo do ano. Boas datas para reuniões gerais do LATIM.

Abono pecuniário não conta como ausência aqui — só períodos de férias de verdade bloqueiam uma janela. Dias úteis = segunda a sexta, descontando feriados nacionais de 2027 (não inclui pontos facultativos como Carnaval ou Corpus Christi). A lista recalcula toda vez que você abre este painel.

Publicar atualização

Este site é uma página estática do GitHub Pages. Com um token de acesso, o botão abaixo publica direto no seu repositório — sem precisar baixar e subir arquivo manualmente.

Não tem um token ainda? No GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Em "Repository access", escolha "Only select repositories" e marque só o ferias-latim. Em "Permissions → Repository permissions", defina Contents: Read and write. Copie o token gerado e cole aqui — ele só é mostrado uma vez pelo GitHub.
Prefiro baixar e subir manualmente
1. Baixe o arquivo. 2. Abra o repositório no GitHub. 3. Substitua planner-data.json pelo baixado. 4. Commit.

Lembretes diários

Enquanto esta aba estiver aberta no navegador, o planner pode avisar no horário escolhido sobre início/fim de férias do dia.

Aviso pelo navegador só funciona com a aba aberta. Para um lembrete garantido no desktop — mesmo com o navegador fechado — use “Exportar lembretes (.ics)” e importe no seu app de calendário (Outlook, Google Calendar ou Calendário do sistema). Cada período de férias entra como um bloco contínuo — visível em todos os dias — com alarme de início no horário escolhido; o último dia entra também como um evento à parte, “Fim de férias de [nome]”, com alarme próprio.
